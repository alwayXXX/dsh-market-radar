# 行情雷达 · dsh-market-radar

在 DeepSeek Harness 官方桌面端的底部查看黄金、A 股和美股自选行情。点开看板查看走势、设置到价提醒，并把行情快照放入当前对话草稿。

`0.1.3` 修复了旧预发行版 `0.1.3-dev.0` 的黄金昨收错误；新版已在 Windows DSH 桌面端完成代表性图表和提醒交互验收。

[English](README.en.md) · [MIT](LICENSE)

## 功能

- 28px 底部行情条，固定最多三只重点标的；底部区域被占用时使用右上角的小入口。
- 黄金、A 股、美股分组，自选添加、排序、固定、删除及 JSON 导入导出。六位 A 股代码可查询候选，确认后添加。
- 国际现货金 XAU（USD/盎司）与 Au99.99（CNY/克）独立报价。
- 价格折线支持 1 天、5 天、1 个月、半年、YTD（年初至今）、1 年、5 年和 Max 切换，横轴显示时间刻度；支持悬停和方向键读数，缺失区间断开绘制。1 天视图提供昨收参考线。
- 高于或低于目标价、当日上涨、下跌及涨跌幅绝对值提醒，默认冷却 15 分钟；既有双向涨跌幅规则继续保留。未读提醒可在应用内查看并标记已读。
- **Ctrl+Shift+F9** 隐藏行情并静音，再按恢复；恢复时不补弹隐藏期间的提醒。
- 用户预览行情快照后，将其放入当前对话草稿；保留已有文字和附件，由用户发送。
- 跟随宿主明暗主题，支持红涨绿跌与绿涨红跌。

## 安装

首个兼容目标为 **DSH 0.2.2-rc.3**，Node.js >=24.9.0。可从 npm 或 GitHub Release 安装预构建包。

在官方桌面端的 Plugins 页面选择本地安装包，或使用桌面端自带 CLI：

使用 CLI 前先完整退出桌面 App（包括托盘进程），让宿主释放 `desktop` profile；安装完成后重新打开 App。

```powershell
& '你的安装目录\resources\runtime\cli\bin\dsh.cmd' plugin --profile desktop add 'dsh-market-radar@0.1.3'
```

旧预发行版 `0.1.3-dev.0` 存在上述黄金昨收问题，请使用 `0.1.3` 或更新版本。

也可从 [GitHub Release](https://github.com/alwayXXX/dsh-market-radar/releases) 下载 `.tgz`，将上述包名替换为安装包绝对路径。桌面端的 `desktop` profile 由 App 管理，使用桌面端自带 CLI。浏览器版使用其对应 CLI 和 `web` profile。安装后重新加载界面。

## 使用

1. 点击底部行情条，打开自选看板。
2. 点击 `+`，选择市场并输入代码，核对返回的标的名称后确认添加。
3. A 股可输入六位代码查询候选，或直接使用 `sh600519`、`sz000001` 等带交易所前缀的代码；`sh000001` 为上证指数，`sz000001` 为平安银行，请核对候选后添加。
4. 美股填写 `AAPL`、`VOO`、`QQQM` 等；黄金选择 `XAU` 或 `AU9999`。
5. 使用图钉固定最多三只标的到行情条，行尾菜单用于排序、设置提醒和移出自选。
6. 点击标的查看走势，使用图表上方的时间按钮切换区间；选择“准备行情快照”，预览后“放入对话”。先打开一个可编辑的对话；此步骤不调用模型。

初始自选仅为功能示例，可以清空或替换。

## 提醒与运行范围

提醒只在最新有效报价上评估。启动、启用规则、重连或修改阈值后的第一条有效报价用于建立基线；之后穿越阈值才提醒，持续满足条件不会重复提醒。默认冷却为 15 分钟，可设置 1–1440 分钟。首版使用应用内提醒记录与数量标记。

涨跌幅阈值输入正数：例如选择“当日跌幅达到”并输入 `3`，表示达到或跌破 **-3%**；原有“涨跌幅绝对值”规则仍会在上涨或下跌达到阈值时触发。新增方向规则保存后，旧版本无法识别该规则；回退前请先导出配置，并在当前版本删除新增规则。

快捷键通过 DSH 原生快捷键服务注册，可在宿主快捷键目录中搜索“行情雷达：隐藏或恢复”修改。Windows 默认 `Ctrl+Shift+F9`，macOS 默认 `Command+Shift+F9`；绑定冲突时可在该目录另行指定组合。Windows 组合经物理键盘测试可隐藏和恢复。

行情监测在 DSH 进程运行且电脑保持唤醒时进行。隐藏模式收起插件的行情界面并静音，恢复时显示当前行情；已主动加入对话的快照继续由 DSH 保留。关闭 App、系统休眠或网络中断期间不保证监测连续。

## 数据来源、时间与隐私

所有行情请求均由本机 DSH Host 发出，无需账号、Cookie 或行情 API Key。请求的域名为：

| 用途 | 域名 |
|---|---|
| A 股、美股报价 | `qt.gtimg.cn` |
| A 股、美股当日分时，A 股五日分时和日线 | `web.ifzq.gtimg.cn` |
| 黄金报价 | `hq.sinajs.cn` |
| XAU 分时和日线 | `stock2.finance.sina.com.cn` |
| 美股五日及日线 | `query1.finance.yahoo.com` |
| Au99.99 日线 | `www.sge.com.cn` |

免费公开接口存在延迟、限流、格式变化与不可用的可能。源站时间与获取时间分别保留，过期报价不参与提醒。休市判断采用常规交易时段；节假日、提前收市和临时休市可能显示为“报价已延迟”。美股时间按 `America/New_York` 处理夏令时。

1 天使用分时数据；Au99.99 暂无历史分时接入，使用运行期间的有效报价采样，首次安装遇到休市可能没有走势。XAU 或股票的当日分时不可用时也回退采样。5 天视图：A 股使用分时、美股使用 5 分钟采样，两种黄金使用 5 个交易日的日线数据。1 个月、半年、YTD、1 年、5 年和 Max 使用日线收盘点；当日数据可能尚未收盘。YTD 从标的所在市场的当地 1 月 1 日起算；Max 展示当前接口及请求上限内可取得的历史，更早数据不保证完整。图表显示实际覆盖范围、来源与粒度，接口无数据时不补造。

A 股日线使用腾讯未复权数据；美股历史数据使用 Yahoo Finance 的 `close`，复权口径以来源为准，除权、拆股可能影响长期曲线。美股 `.INX` 映射至标普 500 指数，其他部分特殊代码可能暂不支持历史走势。免费接口可能更改或停止，不能保证所有代码及时间范围都有完整数据。访问相应来源时，数据服务方可能收到查询的标的代码和网络地址。

自选、提醒和显示设置按 profile 保存在本机插件私有目录，导出 JSON 包含这些设置。行情快照只在点击放入草稿后进入当前对话；用户发送后按 DSH 当前模型配置处理。

## 开发

```sh
pnpm install
pnpm check
pnpm smoke:live
pnpm smoke:history
pnpm smoke:package
pnpm dev
```

开发验证页为 `http://127.0.0.1:4188`，使用真实公开行情接口并模拟宿主插槽和草稿，不等同于实际 DSH。运行 `pnpm pack --pack-destination dist` 生成安装包。React 由 DSH 宿主提供；Host 与浏览器入口均预构建。

## 卸载

通过安装时相同的 profile 移除 `dsh-market-radar`，再重新加载界面。插件释放轮询、网络请求、插槽、快捷键监听及样式；本地自选文件保留，便于恢复。
